# LifeSim — журнал версий и план

Актуальная рабочая версия: **0.0.4.8d**. Основной рабочий файл — `LifeSim.html`
(он же копируется в версионный файл при выпуске).

> Технические заметки для себя:
> - В пассажи Twine HTML-теги хранятся экранированными (`&lt;div&gt;`), а кавычки
>   внутри макросов `<<run f(&quot;...&quot;)>>` — как `&quot;`. Сырой `<div>` в
>   теле пассажа ломает вёрстку (так был сломан пассаж Hospital — починено).
> - Twine сам создаёт пассажи при импорте HTML: достаточно добавить блок
>   `<tw-passagedata name="...">…</tw-passagedata>` в исходник.
> - Тесты — jsdom; окну нужно задать ненулевые размеры (outerWidth/innerWidth),
>   иначе движок SugarCube не стартует. Манипуляции состоянием — только внутри
>   оконного контекста (eval), иначе «attempted to clone unsupported type».

## 0.0.4.8d (текущая) — суточный лимит навыка для проектов, досье на «Основное», свои сообщения о лимите
- **Сообщение о суточном лимите навыка — своё под каждый навык.** Раньше при
  достижении лимита для всех «физических» навыков вылезало «💪 Мышцы забиты»
  (из-за чего садоводство нелепо жаловалось на мышцы), а для остальных —
  «🧠 Голова перегружена». Теперь карта `SKILL_LIMIT_TEXT` + `_skillLimitText()`
  дают отдельную формулировку каждому навыку: спорт — про мышцы, танцы — про
  усталость от танца, садоводство — «руки наработались в земле», кулинария —
  про кухню, уборка — про надраенный дом, ремонт — про инструмент, обаяние —
  «наговорились», программирование — про код/глаза, писательство — про музу,
  рисование — про вдохновение, интеллект — про учёбу. Есть общий fallback.


- **Прокачка навыка при работе над проектами теперь упирается в суточный лимит.**
  Раньше подходы к проекту (создание и доработки) начисляли опыт навыку напрямую,
  в обход `gainSkillXp`/`SKILL_DAILY_ACTIONS` — поэтому, гоняя игру и доработки
  по кругу, можно было за один присест прокачать навык (например, программирование
  с нуля до 3 уровня). Теперь каждый проектный подход идёт через общий дневной
  лимит навыка (`gainSkillXp`, настройка `PROJECT_SKILL_XP = 1` опыт/подход):
  после 5 занятий навыком за сутки опыт больше не капает до следующего дня
  («голова перегружена» / «мышцы забиты»). Прогресс и качество проекта при этом
  продолжают двигаться — работа над проектом не блокируется, не растёт только
  сам навык. Обычная практика и работа используют тот же лимит, что и раньше;
  счётчик по-прежнему сбрасывается в новых сутках.
- **Досье («👤 Персонаж») по умолчанию открывается на вкладке «Основное»** —
  раньше показывались «Навыки». Кнопка в сайдбаре и `openCharacter()` без
  аргумента открывают «Основное»; явное переключение на «Навыки»/«Работа»/
  «Портфолио»/«Статистика» работает как прежде.
- Тесты jsdom: `v048d.js` — 17 проверок (проект не качает навык сверх лимита,
  доработки тоже, лимит сбрасывается на новые сутки, проект доделывается при
  капе навыка, дефолтная вкладка «Основное» и переключение); регрессия
  `vregd.js` — 7/7.

## 0.0.4.8c (текущая) — мягкое замедление качества, доработки, именование работ, портфолио
- **Садоводство сведено к одному действию**: убран дубликат «🪴 Полить домашнее
  растение» из гостиной (там больше нет садоводства) и «🪴 Ухаживать за садом»
  на террасе. Осталось одно действие «🌱 Ухаживать за растением» на террасе
  (30 мин, +досуг/общение, рост садоводства, мудлет умиротворения). Битый
  эмодзи 🪴 (рендерился пустым квадратом) полностью удалён.
- **⚙️ Скорость роста качества вынесена в настройки и сильно понижена.**
  В начале блока проектов теперь три «крутилки», которые можно править вручную:
  `QUALITY_GAIN_BASE` (прирост новичку за подход), `QUALITY_GAIN_PER_MASTERY`
  (добавка за навык), `QUALITY_GAIN_RANDOM` (случайный разброс). Формула за
  подход: `база + за_мастерство×(ур./10) + случайно`, затем × `qf` типа
  (рисунок 2.2, программа/игра/книга 1.0). Значения по умолчанию понижены в
  разы: новичок за полный проход игры набирает ~9% качества (ур.1 ~17%,
  ур.2 ~26%), мастер (ур.10) — ~98–99%; до 100% качеством новичку нужно ~5
  полных проходов-доработок. Комментарий в коде содержит таблицу-ориентир.
- **Качество проектов: вместо жёсткого потолка — мягкое замедление.**
  Функция `skillQualityCapPct` и процентный лок убраны. Прирост качества за
  подход теперь сильно зависит от навыка (`_projectQualityGain`): новичок
  к концу прогресса набирает лишь ~24–36% качества (заметно отстаёт от
  прогресса), тогда как мастер (ур. 10) доходит до 100%. Жёсткого запрета нет —
  качество теоретически догоняется доработками. Звёзды разовых практик
  (`skillQualityCap`) по-прежнему масштабируются уровнем навыка.
- **Доработки после завершения**: когда прогресс 100%, но качество <100%,
  кнопка «🔧 Доработать качество (пройти заново)» (`startRevision`) запускает
  ревизию: **прогресс СБРАСЫВАЕТСЯ в 0 и работа проходится заново**
  (то же число 10-минутных подходов). Качество при этом не сбрасывается и
  медленно растёт по ходу повторного прохождения (та же медленная скорость,
  упирается в низкий навык — без жёсткого лока сверху). Чтобы новичку довести
  качество до 100%, нужно несколько полных проходов; после каждого можно
  опубликовать или отправить на ещё одну доработку. Счётчик проходов
  `revisions` и флаг режима `revising` сохраняются; при 100% качества —
  гарантированные 5 звёзд.
- **Именование работ**: при публикации программы/игры/книги открывается диалог
  с полем названия (кнопки «Опубликовать»/«Отмена» — обычный HTML, работают по
  клику и по Enter; рисунки публикуются сразу с автоподписью «Рисунок №N»).
  Подсказка в правильном падеже («Введите название игры/книги/программы»).
  Жанры/типы/описание — задел на будущее.
- **Вкладка «📁 Портфолио» в досье**: все опубликованные работы сгруппированы
  по типам (рисунки/программы/игры/книги), у каждой — название, звёзды
  качества, день готовности и заработок (поле `earnings` зарезервировано под
  экономику 0.0.4e).
- **Кнопки проектов**: убран дубль «↩️ К выбору занятия» / «💾 Решить позже
  (назад)» — осталась одна «↩️ Назад». В хабах «Мастерская» и «Компьютер»
  кнопка «🚶 Вернуться домой» переименована в «↩️ Назад» (на работе/в больнице
  формулировка про дом сохранена).
- Миграция сейвов дополнена: у старых проектов появляются
  `revisions`/`revising`/`sessions`/`progress`/`quality`, у старых работ —
  `name`/`kindType`/`earnings`.
- Тесты jsdom: `v048c2.js` — 28 проверок (мягкое качество, доработка со сбросом
  прогресса до 100% за несколько проходов, кликабельный диалог именования,
  портфолио, единое садоводство, кнопки); регрессия `vreg2.js` — 7/7.

## 0.0.4.8b (текущая) — баланс качества, навыки с нуля со скрытием, «Компьютер», быстрый старт
- **Исправлен баланс качества**: новичок больше НЕ может сделать шедевр. Введён
  жёсткий потолок качества по уровню навыка (`skillQualityCap`): ур. 0 — только
  1★, ур. 1 — до 2★, ур. 3 — до 3★, ур. 5 — до 4★, ур. 6+ — 5★. У проектов
  итоговое качество ограничено процентом по уровню (новичок не доведёт шкалу
  качества выше ~20–40%), при этом прогресс доделать можно всегда.
- **Навыки начинаются с уровня 0**. В досье показываются только ИЗУЧЕННЫЕ
  навыки; неизвестные скрыты (есть счётчик «известно N из M»). При первом
  занятии новым навыком он открывается с сообщением «🌱 Вы начали изучать
  новый навык: …». Очки в редакторе персонажа делают навык известным сразу.
- **«Компьютер»**: кабинетное действие переименовано в «💻 Сесть за компьютер…»,
  хаб называется «Компьютер». Программирование и писательство — разные навыки
  (практика кода / практика письма / проекты программа-игра-книга).
- **Быстрый старт для разработки**: кнопка «⚡ Быстрый старт (для разработки)»
  в главном меню — сразу создаёт «Роберта» с пресетной внешностью, стартовыми
  навыками (программирование 3, кулинария 2, спорт 2) и богатым домом.

## 0.0.4.8 (текущая) — цветные мудлеты, поэтапные проекты, человечные эмоции
- **Цветные мудлеты**: у каждого мудлета есть тон (`tone`), чип подсвечивается
  цветом — 🟩 зелёный (хорошо), 🟥 красный (плохо/травмы/острое), 🟨 жёлтый
  (неприятно, но не ужас: смущение/скука/усталость лёгкая), ⬜ белый (нейтрально).
- **Поэтапная работа над произведениями** (пассаж `ProjectWork`): рисунок,
  программа, игра и книга создаются много подходов по **10 минут**. Две шкалы:
  синяя — прогресс, золотая — качество (растёт быстрее при высоком навыке).
  По завершении — «🚀 Опубликовать», «🗑️ Удалить», «💾 Решить позже» (последнее
  сохраняет проект и возвращает в хаб навыка). Проекты раздельны по типам.
- **Разделены программирование и писательство**: в кабинете — практика кода,
  практика письма, и проекты (программа/игра/книга). Отдельный навык
  «писательство» используется для книг.
- **Эмоции — в форме «Вы …» / «Вам …»** (род убран, пол персонажа не влияет):
  «Вам весело» вместо «Весел», «Вы довольны/спокойны/раздражены…».
- «Арт» переименован в **«рисунок»** (исправлен род в текстах/тостах).

## 0.0.4.7 (текущая) — навык «писательство», созидание, садоводство, травмы-навсегда, чистка
- **Навык «✍️ Писательство»** добавлен в реестр, стартовое состояние и окно «Персонаж».
- **Пассажи-мастерские с выбором действия** (вместо прямого действия):
  - 🎨 Мастерская (`ArtStudio`): практика рисования / **создать арт**;
  - 💻 Кабинет (`CodeDesk`): практика кода / **написать программу** / **сделать игру** / **написать книгу**;
  - ✍️ Письменный стол (`WritingDesk`): написать книгу.
  - Создание произведения = долгая деятельность (2–4 ч) с готовым результатом,
    качеством 1–5 и мудлетом «Работа завершена». Произведения копятся в
    `player.creations` / `player.works` (позже — продажа/инвентарь).
- **Садоводство 🌱**: полив растения (в гостиной есть комнатное растение —
  доступно во всех домах) и уход за садом на террасе (если есть). Дают опыт
  садоводства и мудлет **🌿 «Умиротворение»** (спокойствие + настроение).
- **Травмы теперь постоянные**: мудлеты ушибов/ожогов/пореза/удара током не
  истекают по таймеру и висят, пока их не вылечат в больнице. В подсказке —
  «(нужно лечение)».
- **Починен интерфейс больницы** (пассаж Hospital): сырой HTML ломал вёрстку —
  кнопки теперь вертикально и по центру, как в окне работы.

## 0.0.4.5 — качество занятий (1–5) и срывы/травмы, эффекты черт
- Качество результата (каляка→шедевр) для рисования/готовки/спорта/программирования,
  тост со звёздами ⭐, мудлеты по итогу.
- Отдельный редкий слой срывов: потянул мышцу / порезал палец / баг в коде /
  испорченный холст.
- Черты влияют: «Творческий» → +качество; «Неуклюжий» → +срывы;
  «Выносливый» → −срывы; «Ленивый» → больше трат энергии.
